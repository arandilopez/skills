# Skills Collection

A collection of reusable agent skills installable with the `skills` CLI.

## Install All Skills

Install every skill from this repository:

```bash
npx skills add arandilopez/skills
```

Install from a local checkout:

```bash
npx skills add .
```

## Available Skills

### rails-i18n

Strict Ruby on Rails internationalization workflow for user-facing strings, locale files, and `i18n-tasks` verification.

Use this skill when working on Rails views, controllers, helpers, mailers, forms, validations, flash messages, page titles, navigation, button labels, error messages, or any feature that adds or changes user-facing text.

Install only this skill:

```bash
npx skills add arandilopez/skills --skill rails-i18n
```
